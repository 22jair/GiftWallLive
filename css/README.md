# CSS

Los estilos siguen la misma separación que JavaScript:

- `core/`: base global, variables, reset y reglas de accesibilidad.
- `components/`: piezas compartidas del escenario: Top 3, showcase, printer y sus componentes.
- `pages/`: estilos de páginas auxiliares, como los catálogos de preview y la galería.

Los estilos propios de cada tema permanecen junto a su diseño (`designs/printer/` o `designs/halloween/`) para que una variante no contamine a la otra.
